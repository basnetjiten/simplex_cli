## 0.1.0

- Initial release.
- `simplex init` — creates `simplex.yaml` project configuration.
- `simplex make feature` — scaffolds a full Clean Architecture feature module with GraphQL (Ferry) or REST (Dio) data source, optional `PagingCubit` support, and optional test stubs.
- `simplex convert` — converts an existing feature's data layer between GraphQL and REST, including `--dry-run` preview mode.
